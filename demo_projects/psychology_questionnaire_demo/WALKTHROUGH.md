# 演示项目操作指引

本目录是一个完整的心理学问卷研究演示项目，包含模拟数据和预期结果。

## 项目背景

研究主题：大学生焦虑与自尊的关系  
量表：焦虑分量表（5 题）+ 自尊分量表（5 题），Likert 5 点  
样本：30 名大学生（含 3 名无效作答者）

## 文件说明

| 文件 | 内容 |
|------|------|
| `data.csv` | 30 行原始数据，含 Q1-Q10 + 人口学 + 时长 |
| `questionnaire_schema.json` | 维度结构、反向题、计分规则 |
| `literature_seed.json` | 3 篇种子文献信息 |
| `expected_analysis_cards.json` | 预期分析结果 |

## 操作步骤

### 1. 导入数据

- 打开系统，进入「📋 问卷设计 → 📊 问卷数据导入与清洗」
- 上传 `data.csv`
- 系统自动识别 Q1-Q10 为题项列

### 2. 维度配置

按 `questionnaire_schema.json` 设置：

**焦虑维度：**
- 题项：Q1, Q2, Q3, Q4, Q5
- 反向题：Q3
- 量表范围：1-5

**自尊维度：**
- 题项：Q6, Q7, Q8, Q9, Q10
- 反向题：Q8, Q9
- 量表范围：1-5

### 3. 清洗

- 时长列：duration_seconds
- 最短时长：60 秒
- 预期：剔除 3 例（id=5, 12, 28，时长 < 60s）
- 有效样本：27

### 4. 方法推荐

设置：
- 研究目的：相关分析（correlation）
- 因变量类型：连续
- 样本量：27

预期推荐：Pearson 相关

### 5. 证据表

导入 `literature_seed.json` 中的 3 篇文献：
- wang2023：焦虑与自尊的负相关关系
- li2022：大学生心理健康
- zhang2021：自尊的测量工具

### 6. 预期分析结果

见 `expected_analysis_cards.json`：
- 方法：pearson_corr
- 预期：焦虑与自尊呈负相关

### 7. 交付包

标准版交付包应包含：
- 论文正文（引言 + 方法 + 结果）
- 统计结果卡
- 文献证据表
- 数据清洗日志
- 参考文献
