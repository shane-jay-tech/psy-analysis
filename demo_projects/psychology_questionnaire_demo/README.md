# 演示项目：大学生焦虑与自尊关系

## 研究目的

探索大学生焦虑水平与自尊水平之间的关系。

## 数据说明

- `data.csv`：模拟问卷数据，30 名大学生，10 道 Likert 5 点题
- 焦虑分量表：Q1-Q5（Q3 反向计分）
- 自尊分量表：Q6-Q10（Q8、Q9 反向计分）
- 人口学：性别、年级
- 包含 3 个无效样本（作答时间 < 60 秒）

## 演示路径

1. 导入 `data.csv`
2. 运行问卷清洗（按 `questionnaire_schema.json` 配置）
3. 运行信度分析（两个维度）
4. 运行描述统计
5. 运行 Pearson 相关（焦虑 × 自尊）
6. 加载文献种子（`literature_seed.json`）
7. 文献审核确认
8. 论文写作生成
9. 健康检查
10. 导出

## 预期结果

- 清洗后 N=27（剔除 3 个无效）
- 焦虑和自尊信度 α > 0.70
- 焦虑与自尊负相关
- 详见 `expected_analysis_cards.json`

## 注意

本数据为模拟生成，不含真实个人信息。
