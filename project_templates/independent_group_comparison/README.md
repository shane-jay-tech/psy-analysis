# 模板：独立样本组间比较

## 适用场景
比较两个独立组在某指标上的差异。

## 示例研究
- 研究主题：正念冥想对焦虑水平的影响
- 假设：实验组焦虑得分显著低于对照组
- 设计：随机分组，实验组接受 4 周正念训练
- 样本：60 名大学生（实验组 30 + 对照组 30）

## 变量角色
- dv: 连续因变量（焦虑后测得分）
- iv: 分组变量（实验组 / 对照组）

## 推荐方法
独立样本 t 检验（正态且方差齐）/ Welch t 检验（方差不齐）/ Mann-Whitney U（非正态）

## 前提假设
- 因变量为连续变量
- 两组独立
- 正态性（Shapiro-Wilk）
- 方差齐性（Levene 检验）

## 预期产出
- t 值、df、p 值、Cohen's d
- 均值标准误图
- APA 格式结果报告
