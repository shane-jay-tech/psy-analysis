# 模板：前后测实验

## 适用场景
同一组被试在干预前后的变化比较（配对样本设计）。

## 示例研究
- 研究主题：团体辅导对社交焦虑的改善效果
- 假设：干预后社交焦虑显著降低
- 设计：单组前后测
- 样本：35 名社交焦虑大学生

## 变量角色
- dv: 连续因变量（社交焦虑得分）
- iv: 时间点（前测 / 后测）

## 推荐方法
配对样本 t 检验（差值正态）/ Wilcoxon 符号秩检验（差值非正态）

## 前提假设
- 因变量为连续变量
- 配对数据（同一被试两次测量）
- 差值的正态性

## 预期产出
- t 值、df、p 值、Cohen's d
- 前后均值对比图
- APA 格式结果报告
