# 模板：问卷相关研究

## 适用场景
探索两个心理变量之间的相关关系。

## 示例研究
- 研究主题：大学生焦虑与自尊的关系
- 假设：焦虑与自尊呈显著负相关
- 量表：焦虑分量表（5题）+ 自尊分量表（5题），Likert 5 点
- 样本：50 名大学生

## 变量角色
- x: 连续变量 1（焦虑得分）
- y: 连续变量 2（自尊得分）

## 推荐方法
Pearson 相关分析（正态性满足时）/ Spearman 秩相关（正态性不满足时）

## 前提假设
- 两个变量均为连续变量
- 线性关系（散点图检查）
- 无极端异常值
- 正态性（Shapiro-Wilk 检验）

## 预期产出
- 相关系数 r 及显著性 p
- 散点图（含趋势线）
- APA 格式结果报告

## 文件说明
| 文件 | 内容 |
