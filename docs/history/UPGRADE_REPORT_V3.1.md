# Psy Analysis v3.1 升级报告

**升级日期**：2026-05-17
**版本定位**：v3.0 AI 陪练 → **v3.1 多项目 + 对话留存**
**升级范围**：把"工作区"从单一概念升级为"多个独立项目"，AI 助教对话不再随浏览器关闭丢失

---

## 1. 升级动因

v3.0 实施完后，用户给出真实痛点反馈：
1. **多个研究并行**：本科 4 年间会写多份课程报告/课程论文/毕业论文，单一 workspace 不够用
2. **AI 助教对话丢失**：关浏览器后历史消失，无法回顾之前的讨论

我之前在 v3.0 后的"边际价值"评估里把这两件事标为"低优先级"，**这个判断错了**。它们不是边缘需求，是真实工作流的核心。v3.1 修正这个判断。

## 3. 核心功能详解

### 3.1 多研究项目管理

**数据模型**：
```
~/.psy_analysis/
└── projects/
    ├── index.json              # 所有项目元信息列表
    ├── <id1>.json              # 项目1 工作区（df + 分析 + 收藏图 + 对话历史）
    ├── <id2>.json              # 项目2 工作区
    └── ...
```

**Project 字段**：id (UUID12) / name / created_at / updated_at / note

**支持操作**：
- ✅ 列出所有项目（按最近访问排序）
- ✅ 新建（指定名称 + 备注）
- ✅ 切换（自动保存当前 + 加载目标）
- ✅ 重命名 / 修改备注
- ✅ 复制（含完整工作区数据，"X (副本)"）
- ✅ 删除（最后一个项目删除时自动新建空项目）
- ✅ 导出为 JSON / 从 JSON 导入

**自动行为**：
- 首次启动：检测 v3.0 的 `~/.psy_analysis/autosave.json` → **一次性迁移**为"自动恢复的工作区"项目，删除旧文件
- 已有项目：自动加载最近访问的
- 全新用户：创建默认"我的研究"项目

**UI 位置**：侧边栏「📂 我的项目」面板
- 当前项目名 + 备注显示
- 切换下拉
- 新建/重命名/复制/删除按钮
- 导出/导入 expander

**保留全局状态**（不随项目切换丢失）：
- LLM 配置（API key、provider、model）
- 隐私接受、引导完成标记
- 启动检查状态

### 3.2 AI 助教对话持久化

**之前**（v3.0）：对话存 `st.session_state["_tutor_history_step6"]`，关浏览器即丢
**现在**（v3.1）：对话作为工作区的一部分，保存到当前项目的 JSON

**序列化策略**：
- `ChatMessage` 转为 `{"role": "user", "content": "..."}`
- workspace 字段：`tutor_histories` = `{"_tutor_history_step6": [...], "_tutor_history_step7": [...]}`
- 第 6 步、第 7 步独立对话历史（不互通）

**UI 增强**：
- 对话面板底部加「📥 导出 MD」按钮 — 把整个对话生成 Markdown，方便回放
- 「🗑 清空对话」单独保留
- 提示文字："对话历史：N 条（已自动保存到当前项目）"

**项目隔离**：每个项目有独立对话历史，切换项目自动加载对应对话

### 3.3 autosave 项目级改造

**v3.0**：写到固定 `~/.psy_analysis/autosave.json`
**v3.1**：写到当前活跃项目的 JSON 文件

调用方代码不变（仍是 `trigger_autosave(session_state, builder)`），语义升级：
- 自动取 session_state 中的活跃项目 ID
- 调 `project_manager.save_workspace(active_id, ws)`
- 节流逻辑保留（30s 内不重复写）
- 无活跃项目时静默 False（不会崩）

`render_restore_prompt(st)` 退化为空操作（迁移已挪到 `ensure_active_project_on_first_visit`）。

## 6. 已知局限

| 项 | 说明 | 应对 |
|---|---|---|
| 项目存储无加密 | JSON 明文（含 base64 CSV）| 单用户场景；分享前需注意脱敏 |
| 对话历史保留最近 10 轮（送 LLM）| token 限制 | 完整历史仍保留在 session/项目，UI 可全部回看 |
| 项目切换会清 session_state | 保留 LLM 配置等全局项 | 已显式列出保留键，避免误清 |
| 无项目搜索 / 标签 / 排序 | 当前按"最近访问"排序 | 项目数 < 20 时够用；>20 时考虑加搜索 |
| 多项目共享演示数据 | 每个项目独立加载 | 设计上：项目应彼此隔离 |

## 8. v3.1 设计哲学

> "AI 陪练" → "陪练记得住，研究分得清"

v3.0 让 AI 能针对具体研究答得到点子上，但每个会话都是"重新认识"。
v3.1 让 AI 助教**记得你之前问过什么**——对话不再随浏览器关闭丢失。

更重要的是，v3.1 承认**本科生不只一个研究**：
- 大三《心理统计》课程作业
- 大三《实验心理学》课程报告
- 大四毕业论文（试点 + 正式 + 修改稿）

每个都是独立项目，互不干扰，但**复制功能**让"在副本上重做对照分析"变得简单。

**架构哲学的转变**：
- v3.0：session_state 是真理来源
- v3.1：当前项目是真理来源，session_state 是它的运行时投影
