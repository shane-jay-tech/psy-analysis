## 一、系统概述

本系统面向中国心理学研究者，覆盖心理学实证研究的**全流程**（从文献调研到论文撰写），基于 Streamlit 构建 Web 界面，包含四大核心功能模块：

| 模块 | 定位 | 能力 |
|------|------|------|
| 数据分析 | 自然语言输入 → 统计推断 → 可视化 → APA7 报告 | 27 种分析方法 |
| 问卷设计 | 构念识别 → 维度推断 → 题目生成 → 质量检查 → 信效度 → 多格式导出 | 7 领域句型模板 + 学术库 |
| 实验设计 | 研究方向 → 模板推荐 → 效力分析 → 拉丁方 → jsPsych 脚本 | 7 类设计模板 |
| 论文写作 | 研究信息 + 分析结果 → 文献管理 → 确认问题 → APA7 初稿 | 113 篇预置文献 |

## 二、各子系统详细评估

### 2.1 数据分析子系统 (`src/analysis/` — 4,212 行，10 个模块)

**架构：注册表模式（Registry Pattern）**

27 个分析处理程序通过 `@_register("test_type")` 装饰器注册，替代 if/elif 分支链。新增分析方法只需编写处理函数并加装饰器，无需修改调度代码。暴露 `register_custom_handler()` 接口支持用户运行时注入自定义方法。

**统计方法全覆盖：**

| 类别 | 已实现的方法 | 效应量 | 事后检验 |
|------|-------------|--------|---------|
| t 检验 | 独立样本 / 配对 / 单样本 | Cohen's d, dz | — |
| ANOVA | 单因素 / 两因素 / 重复测量 | η² | Tukey HSD |
| 非参数 | Mann-Whitney U / Wilcoxon / Kruskal-Wallis / Friedman | r, ε², W | Dunn + Bonferroni |
| 相关 | Pearson / Spearman / 偏相关 / 点二列 | r, r_pb | — |
| 回归 | 简单线性 / 多元（含 VIF）/ 分层（ΔR²） | f² | — |
| 卡方 | 独立性检验 / 拟合优度 | Cramer's V | 标准化残差 |
| 信度 | Cronbach's α + 分半（Spearman-Brown） | — | α-if-item-deleted, CITC |
| 因子 | EFA（平行分析 + varimax/promax）+ CFA（semopy） | — | KMO, Bartlett |
| 高级 | ANCOVA / 中介（bootstrap 5000次）/ 调节（简单斜率） | η², f² | bias-corrected CI |
| 数据质量 | 缺失值（4种方法）/ 异常值 / 变量类型推断 | — | — |

**每条分析路径均输出：** 描述统计 → 假设检验（正态性/方差齐性）→ 检验统计量 → 效应量 + 95% CI → APA7 解读文本 → 可视化图表

**快照系统：** SHA256(数据哈希 + 参数哈希 + 时间戳) 唯一标识分析运行，支持可复现性。

**评分：A**

已知限制：
- 缺少 HLM/多层线性模型
- 缺少元分析
- 极大数据集（>100 万行）需后端分离

### 2.2 问卷设计子系统 (`src/questionnaire/` — 5,108 行，12 个模块)

**构念知识库：**

- 32+ 心理学构念，覆盖 7 个领域（临床与健康、社会、教育、认知、组织行为、人格、发展）
- 每个构念含：学术定义、多维理论框架、已有成熟量表、APA7 参考文献
- 领域关键词两轮评分匹配（优先更长/更具体的构念名）
- 7 个领域专用维度推断模板（如组织行为学不套用 ABC 模型）

**自主学习引擎：**

- 在线文献搜索 → LLM 结构化提取 → 验证 → 存储到 `construct_kb_extended.py`
- 可信度评分：内置=1.0 | Crossref+DOI验证=0.95 | Crossref=0.9 | LLM=0.6 | 被标记=减0.5
- 扩展知识库独立存储，不覆盖内置条目
- 问题条目 `flag_invalid_entry()` 后自动重算可信度

**学术数据库集成：**

- Crossref API 检索已发表量表（7 天缓存）
- 自动提取：作者、年份、DOI、Cronbach's α、题数、信度常模
- 生成 APA7 格式参考文献和信度常模摘要

**题目生成：**

- 6 个领域句型模式字典，每个领域含：正向句型(8-12个) + 反向句型(4-6个) + 领域词汇(4个词槽)
- 语义反向系统：20 对正-反对 + 三步回退策略（直接替换→反义词替换→追加否定词）
- LLM 增强（可选）：3-shot 示例 + 中文量表编写指引 + 迭代精炼
- 模板引擎回退（无 LLM 时）：上下文感知词槽填充

**题目质量检查：**

- 语法检查（否定不当检测、句式完整性）
- 长度检查（<5 字或 >40 字标记）
- 双重含义检测（含 "和/或/与" 连接两个概念）
- 冗余检查（同维度题目余弦相似度 >0.85 警告）
- 平衡检查（正反向题比例验证）

**信效度保障：** 内容效度 + 表面效度 + 构念效度 + 内部一致性信度 + 重测信度，各维度书面策略

**导出：** Word (.docx) / PDF (.pdf) / HTML (.html)，含完整设计报告

**评分：A-**

已知限制：
- 模板引擎回退生成的题目质量低于 LLM 生成（句式相对单一）
- 题目质量检查缺少区分度指标（需要预测试数据）
- 语义反向对复杂抽象句式的处理偶有不自然
- CNKI/万方等中文数据库未集成

### 2.3 实验设计子系统 (`src/experiment_design/` — 2,798 行，5 个模块)

**设计模板（7 类）：**

| 模板 | 设计类型 | 适用场景 |
|------|---------|---------|
| 单因素被试间 | between_subjects | 基础实验研究 |
| 单因素被试内 | within_subjects | 认知/感知实验 |
| 多因素被试间 | between_subjects | 交互作用研究 |
| 混合实验设计 | mixed | 干预研究、发展研究 |
| 问卷调查研究 | survey | 相关关系、中介调节 |
| 干预研究（前测-后测） | mixed | 临床/教育心理 |
| 启动实验 / IAT | within/between | 内隐态度/刻板印象 |

**统计效力分析：**

基于 scipy 非中心 t/F/χ² 分布的精确样本量计算，覆盖 6 种检验类型：
- 独立/配对 t 检验、单因素/重复 ANOVA、双因素 ANOVA、相关分析、卡方检验
- 自动效应量标签（Cohen's 基准：小/中/大）
- 输出中文效力报告，含实际效力 + 实操建议（考虑 10-20% 无效作答率）
- 免检版 `quick_sample_size()` 函数

**实验程序构建：**

- 6 阶段标准化实验流程（准备→知情同意→指导语→练习→正式实验→事后说明）
- **平衡拉丁方**：Bradley (1958) 算法处理偶数条件，奇数 n → 2n 行镜像法
- 每阶段含检查清单 + 时间线可视化
- 随机化方案生成（简单随机/分层随机/区组随机）
- 被试费预算估算（可选）

**jsPsych v7 脚本生成：**

- 被试间：随机分组 + 条件试次 + 操纵检查
- 被试内：拉丁方平衡顺序 + 分块指导语 + 休息间隔
- 问卷：survey-likert 插件集成
- 题项转换：问卷题目 → jsPsych 李克特量表格式

**评分：A**

已知限制：
- 缺少单被试实验设计（single-subject design）
- 缺少 PsychoPy 脚本生成
- 缺少预注册模板（OSF/AsPredicted）

### 2.4 论文写作子系统 (`src/paper_writer/` — 3,660 行，5 个模块)

**论文引擎：**

- 研究信息管理（主题、假设、方法、讨论要点）
- 信息缺口检测 → 自动生成确认问题（9 个预定义模板 × 3 个优先级）
- 完整论文初稿生成：标题 → 摘要 → 关键词 → 引言 → 方法 → 结果 → 讨论 → 参考文献
- 从数据分析模块导入结果（t/F/χ²/r 等统计量）
- LLM 润色（保留数据完整性：不篡改数值，只优化表达）
- 多格式导出（Markdown/Word/HTML）

**文献管理：**

- **113 条预置 APA7 参考文献**（67 中文 + 46 英文），按 7 个领域组织
- DOI 验证（正则格式校验 + Crossref 在线解析）
- DOI 自动补全文献信息（`autofill_from_doi`）
- BibTeX/CSV/JSON 文件导入 + 手动添加
- 文献去重与相关性标注

**格式标准：**

- APA 7th Edition 引用格式（非 GB/T 7714）
- 统计报告符号映射：M、SD、t(df)、F(df1, df2)、χ²(df, N)、η²、Cohen's d
- 显著性标记：*p < .05, **p < .01, ***p < .001（带前导零或无，按 APA7 分情况处理）
- 效应量解读指引（Cohen / Hattie 基准）
- 中英文学术短语库

**评分：A-**

已知限制：
- 章节生成依赖规则+模板，段落灵活性有限
- 未集成 CNKI/万方等中文主要数据库
- 缺少引用格式自动校验（交叉引用一致性检查）

### 3.4 中文本地化：A

- 全中文界面（错误信息、警告、日志、报告、图表标签）

## 九、结语

系统从最初的仅支持部分统计分析方法（部分关键词可识别但不可执行），发展至 **27 种可执行分析方法 + 问卷设计 + 实验设计 + 论文写作**的全流程覆盖。架构从长 if/elif 分支重构为注册表模式。代码总量从 ~2,000 行增长到 21,434 行。

**核心判断：该系统已达到支持标准化心理学实证研究全流程的水平。一个研究者可以从文献调研开始，经过问卷编制（或实验设计）、数据收集、统计分析，到论文初稿完成，全程在本系统内完成。**

**可投入使用的状态：是。** 建议在实际使用中根据具体研究场景扩展内置文献库和构念知识库。
