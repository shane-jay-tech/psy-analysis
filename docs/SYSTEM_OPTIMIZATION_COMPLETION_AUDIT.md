## 环境跳过与残余风险

- 浏览器套件核验结果：15 个非浏览器契约通过，25 个 Playwright 用例跳过；原因是 `.venv` 未安装 `playwright` Python 包。发布到要求浏览器认证的环境前，应安装 Playwright/Chromium 并重跑三个浏览器套件。
- `RLock` 仅覆盖单进程；未来若允许多个应用实例同时写同一项目，应引入 OS 文件锁或事务型存储。
- 大工作区仍需同步序列化完整快照；后续优先评估增量资产与后台快照队列。
- `app.py` 仍承担较多编排职责；后续按页面控制器拆分，保持现有路由与工作区契约不变。
- 论文草稿、作业包、正式交付仍有多个出口；本轮已统一正式导出硬门禁，下一轮继续收敛入口语义。
