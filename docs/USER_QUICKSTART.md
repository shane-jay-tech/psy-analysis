# Psy-Analysis 快速开始指南

**适用版本**: v5.3+  
**适用用户**: 心理学本科生 / 首次使用者

---

## 这是什么工具？

Psy-Analysis 是一个心理学论文数据分析辅助工具。它帮你：

- 选择合适的统计方法
- 执行统计分析
- 生成 APA 格式的表格和图表
- 撰写结果段落
- 导出可编辑的 Word 论文和完整交付包

**重要提示**: 本工具不是诊断工具，不能替代专业统计咨询，所有输出需经导师审阅后使用。

---

## 5 分钟快速上手

### 第 1 步：启动系统

双击 `run.bat`（Windows）即可启动。系统会在浏览器中打开。

如果启动失败：
- 确认已安装 Python 3.10+
- 运行 `pip install -r requirements.txt` 安装依赖
- 查看 `docs/INSTALLATION_TROUBLESHOOTING.md`

### 第 2 步：选择模板创建项目

进入"模板中心"，选择与你论文最接近的模板：

| 模板 | 适用场景 |
|------|----------|
| 问卷相关研究 | 探索变量之间相关关系 |
| 独立样本组间比较 | 比较两组或多组差异 |
| 前后测实验 | 比较干预前后变化 |
| **中介模型** | A 通过 B 影响 C |
| **调节模型** | B 改变 A→C 的强度 |
| **量表信效度** | 检验量表的可靠性和有效性 |

选择后系统会载入示例数据，你可以替换为自己的数据。

### 第 3 步：查看"下一步推荐"

进入"📊 项目状态"页面，系统会告诉你接下来应该做什么。按照推荐的顺序操作即可。

### 第 4 步：执行分析

- 定义变量（哪个是自变量、因变量等）
- 接受系统推荐的分析方法
- 点击"执行分析"

### 第 5 步：导出论文

分析完成后：
1. 检查结果卡片（确认统计数值合理）
2. 运行"一致性检查"（确保无错误）
3. 点击"📦 交付包导出"
4. 下载 Word 文件和 ZIP 交付包

---

## 导出的文件是什么？

### Word 文件（.docx）
- 可直接编辑的论文草稿
- 包含 APA 格式的统计表格（可编辑，不是图片）
- 包含 APA 格式的统计图表

### ZIP 交付包
```
你的项目名/
├── paper.docx          ← 论文 Word 文件
├── tables/             ← 所有统计表格（CSV + Markdown）
│   ├── apa_tables.json ← 表格索引
│   └── table_001_*.csv ← 各表格数据
├── figures/            ← 所有统计图表（PNG）
├── manifest.json       ← 交付清单
└── quality_report.json ← 质量检查报告
```

## 常见问题

### "导出被阻断了"怎么办？
系统检测到可能包含敏感信息（如手机号、身份证号）。请检查数据中是否包含个人信息，删除或替换后重新导出。

### "LLM 不可用"怎么办？
AI 辅助功能暂时不可用（可能是网络问题）。不影响统计分析和导出，你可以继续使用离线功能。

### "CFA/SEM 不收敛"怎么办？
样本量可能不够（建议 ≥200）或模型太复杂。尝试简化模型结构或增加样本量。

### 表格/图表能直接放论文里吗？
表格是可编辑的 Word 表格，可以直接调整。图表是 PNG 格式。都按照 APA 格式生成，但建议和导师确认后再使用。
