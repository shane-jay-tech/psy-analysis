# 已知限制与降级策略

---

## 功能限制

| 限制 | 影响范围 | 降级策略 |
|------|---------|---------|
| Logistic 系列细分不完整 | 二元/有序/多项 Logistic 解释有限 | 标记为"高级方法"，使用基础卡片 |
| MANOVA 结果卡片缺失 | 多元方差分析结果展示不完整 | 使用通用输出格式 |
| ICC 评估卡片缺失 | 评分者一致性结果需手动解释 | 输出原始数值供用户解读 |
| 部分 advanced 方法无 APA 表格 | 中介/SEM 等需手动排版 | 结果卡片仍可用 |
| 无 Mac/Linux 支持 | 仅限 Windows 用户 | 未来版本计划 |
| 无云端部署 | 必须本地安装 | 提供安装指南 |

---

## 环境限制

### 无 Word/LibreOffice 时
- Word 导出正常（使用 python-docx，不需要 Word 软件）
- PDF 转换不可用
- 降级提示："PDF 不可用，请手动在 Word 中导出"

### 无 LLM API Key 时
- 统计分析、表格、图表、导出全部正常
- 方法推荐、论文段落生成、智能解释不可用
- 降级提示："AI 功能不可用，可手动选择方法"

### 无网络时
- 核心功能全部可用（离线设计）
- 仅 AI 功能不可用
- 无降级提示（默认即离线模式）

### 中文字体缺失时
- 图表中中文可能显示为方框
- Word 导出不受影响
- 降级提示："安装 SimHei 字体可改善图表显示"

### Playwright 未安装时
- E2E 测试跳过
- 核心功能不受影响
- 这是开发/测试依赖，用户不需要

## 数据限制

| 限制 | 阈值 | 行为 |
|------|------|------|
| 最大文件大小 | 约 100MB | 提示选择部分列 |
| 最大行数 | 约 100 万行 | 可能变慢但不崩溃 |
| 最大列数 | 无硬限制 | 变量选择界面可能拥挤 |
| 缺失值处理 | listwise 为默认 | 提示缺失比例 |
| 分类变量水平数 | 无硬限制 | 超过 10 级时提醒 |

---

## 统计方法限制

### 默认推荐方法（完整支持）
- Pearson/Spearman 相关
- 独立/配对 t 检验
- 单因素/双因素方差分析
- 重复测量方差分析
- 非参数检验（Mann-Whitney, Wilcoxon, Kruskal-Wallis）
- 卡方检验
- 多元/层次回归
- Cronbach's α / McDonald's ω
- 描述统计

### 高级方法（大部分有 APA 表格）
- 中介分析（路径系数表 + Bootstrap CI 表）
- 调节分析（回归系数表 + 简单斜率表）
- Logistic 回归（B/SE/Wald/OR/CI 表）
- EFA/CFA/SEM（因子载荷表 / 模型拟合表）
- HLM/混合效应（固定+随机效应表）
- AVE/CR/区分效度（无自动表格，结果卡片可用）

### 实验性方法（基础支持）
- 标记为"实验性"的方法未注册结果卡片
- 输出为原始格式，需要用户自行整理

## 安全与隐私限制

- 数据存储在本机，不自动上传
- AI 调用前会提示用户确认
- 导出前隐私预检可能有假阴性（未覆盖所有敏感模式）
- 使用日志可被用户关闭和清除
- 不适用于涉及真实患者数据的临床研究
