# 交付包使用指南

**适用版本**: v5.3+  
**适用场景**: 毕业论文提交、导师审阅、答辩材料准备

---

## 什么是交付包？

交付包是系统为你生成的完整论文材料集合，包含：
- 论文 Word 文件（可编辑）
- 统计表格（多种格式）
- 统计图表（PNG）
- 质量检查报告
- 交付清单

---

## 交付包结构

```
你的项目名.zip
├── paper.docx              ← 主论文文件
├── tables/                 ← 统计表格目录
│   ├── apa_tables.json     ← 表格索引（含编号、方法、标题）
│   ├── table_001_*.csv     ← 表格数据（Excel/SPSS 可打开）
│   └── table_001_*.md      ← 表格预览（Markdown 格式）
├── figures/                ← 统计图表目录
│   ├── figure_001_*.png    ← 图表文件
│   └── figures_index.json  ← 图表索引
├── manifest.json           ← 完整交付清单
└── quality_report.json     ← 质量检查报告
```

---

## 各部分说明

### paper.docx（主论文文件）

- APA 格式排版
- 表格是**可编辑的 Word 表格**，不是图片
- 可以直接在 Word 中修改内容
- 三线表样式（无竖线）
- 中英文双字体支持

**使用建议**：
- 先通读全文，对 AI 生成的段落进行修改
- 检查表格数值是否与你理解的一致
- 添加自己的讨论和结论
- 最终提交前请导师审阅

### tables/（统计表格）

每张表提供三种格式：
- `.csv`：可用 Excel 打开编辑
- `.md`：可在 Markdown 编辑器中预览
- `apa_tables.json`：所有表格的结构化数据

**表格编号规则**：Table 1, Table 2, ... 按分析顺序自动编号。

**APA 表格要求**：
- 无竖线（只有顶线、栏目线、底线）
- 表题在表格上方（斜体）
- 表注在表格下方（含 N、缩写说明、显著性标记）

### figures/（统计图表）

- PNG 格式，300 DPI
- APA 风格（白底、清晰标签）
- 中文标题和坐标轴

### manifest.json（交付清单）

记录每个文件的：
- 路径
- 类型（表格/图表/论文/报告）
- 对应的分析方法
- 生成时间

### quality_report.json（质量报告）

包含一致性检查结果：
- ERROR：必须修复的问题
- WARN：建议关注的问题
- 所有检查通过才建议提交

---

## 导出前注意事项

1. **运行一致性检查** — 确保无 ERROR 级别问题
2. **查看隐私预检结果** — 确保无敏感信息泄露
3. **检查表格数值** — 与分析结果一致
4. **确认引用完整** — 正文引用的表格/图表都存在

## 常见问题

### 表格能直接用在论文里吗？
可以，Word 中的表格是可编辑的 APA 格式。但建议：
- 核对数值准确性
- 根据导师要求调整列名
- 补充必要的表注说明

### 图表格式不对怎么办？
- 图表是 PNG 格式，可以用图片编辑器调整
- 如果需要矢量图（SVG），可以重新导出单张图表
- 中文字体缺失会导致方框字符，安装 SimHei 字体即可

### ZIP 里的文件能单独使用吗？
可以。每个文件都是独立的，可以单独取出使用。

### 导师要求 PDF 格式怎么办？
- 如果系统检测到 Word/LibreOffice，会自动生成 PDF
- 否则可以手动在 Word 中"另存为 PDF"
- 也可以使用在线转换工具（注意隐私）
