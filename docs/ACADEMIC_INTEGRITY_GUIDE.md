# 学术诚信与 AI 辅助使用指南

**适用版本**: v5.4+  
**适用读者**: 使用本工具的学生

---

## 核心原则

1. **工具辅助计算，你负责理解**
2. **AI 生成内容是草稿，不是定稿**
3. **导师审阅是必须的，不是可选的**
4. **答辩时你要能解释清楚每一步**

---

## 什么是允许的

| 允许 | 说明 |
|------|------|
| 用工具做统计计算 | 和用 SPSS/R 一样，是合理的 |
| 用工具生成 APA 表格 | 表格格式是规范化的，用工具更准确 |
| 用工具检查一致性 | 相当于让程序帮你校对 |
| 参考 AI 生成的结果段落 | 但必须用自己的话重写 |
| 使用工具推荐的方法 | 但必须理解为什么用这个方法 |

---

## 什么是不允许的

| 不允许 | 为什么 |
|--------|--------|
| 直接提交 AI 生成的段落 | 这不是你的学术产出 |
| 不理解就用工具推荐的方法 | 你无法在答辩中解释 |
| 隐瞒使用了辅助工具 | 违反学术透明原则 |
| 用工具分析后不检查结果 | 工具可能有 bug，结果需要你判断合理性 |
| 用工具替代研究设计思考 | 研究问题和假设是你的工作 |

---

## 建议的使用方式

### 第 1 步：自己先想
- 确定研究问题
- 提出假设
- 设计数据收集方案
- 初步判断应该用什么方法

### 第 2 步：用工具验证和执行
- 用工具确认方法选择是否合理
- 执行统计分析
- 检查结果是否符合预期

### 第 3 步：理解结果
- 能用自己的话解释每个数值的含义
- 能解释为什么选这个方法
- 能说明结果的实际意义

### 第 4 步：撰写论文
- 用自己的语言写方法和结果段落
- 参考工具生成的表格，但要核对
- 讨论和结论完全由自己撰写

### 第 5 步：导师审阅
- 向导师说明使用了辅助工具
- 接受导师对方法和结果的修改意见
- 确保最终版本反映你的理解

---

## 在论文中如何注明

建议在方法部分添加类似表述：

> 数据分析使用 Psy-Analysis 统计辅助工具完成统计计算和表格生成，
> 方法选择和结果解释由研究者独立完成并经导师审阅确认。

---

## 答辩准备

答辩时你应该能回答：

1. 你为什么选择这个统计方法？
2. 这个方法的前提假设是什么？你的数据满足吗？
3. 结果中的关键数值（如 p 值、效应量）代表什么？
4. 如果结果不显著，可能的原因是什么？
5. 你的研究有什么局限性？

如果这些问题你回答不了，说明你还没有真正理解——回去重新学习统计原理，不要只依赖工具。

---

## 工具的定位

```
研究设计  →  你的工作
数据收集  →  你的工作
方法选择  →  你做主，工具建议
统计计算  →  工具执行，你核实
表格生成  →  工具排版，你审查
结果解释  →  你的工作，工具辅助
论文撰写  →  你的工作
答辩准备  →  你的工作
```

---

## 红线

以下情况构成学术不端，可能导致严重后果：

- 提交未经理解的 AI 生成论文段落
- 伪造或篡改统计结果
- 隐瞒数据清洗中删除不利数据的行为
- 声称手动完成的工作实际由工具完成
- 使用他人数据但未注明来源
