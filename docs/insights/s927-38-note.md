## 3. 本单的生产码改动：except 面收窄为「环境/第三方」已知异常

```python
except (ImportError, AttributeError, OSError, ValueError, NotImplementedError):
```

逐类出处（matplotlib 3.11.0，`.venv` 实测；`font_manager.py:1851` 的 `fontManager = _load_fontmanager()` 是**模块级求值**，
所以这些失败都落在 try 块内）：

| 异常 | 为什么算「环境侧」 | 证据位置 |
|---|---|---|
| `ImportError` | matplotlib 缺失或装坏；本模块另外五个检查项用的就是同款只接 `ImportError` | `environment_diagnosis.py:68/76/83/90/119` |
| `AttributeError` | `fm.fontManager` 属性面、`FontEntry.name` 缺失（ mpl API 漂移） | try 块 `:106` |
| `OSError` | 字体目录遍历与字体缓存读失败；`PermissionError`／`FileNotFoundError` 均是它的子类 | `_load_fontmanager()` 的文件系统面 |
| `ValueError` | weight／stretch 校验与 findfont 兜底 | `font_manager.py:997`、`:1022`、`:1623` |
| `NotImplementedError` | 非矢量字体不被支持 | `font_manager.py:545` |

**被排除的**：`TypeError`／`KeyError`／`IndexError` 等——正是本模块自己的 bug 形状。
s922-118 当年吃的就是这种亏：真 bug 被伪装成「这台机器没装字体」，任何机器都看不到红灯。
detail 文案 `无法检测字体` 与原 `required=False` 均**逐字未动**（零版式漂移，`:199`／`:207` 的在册断言不受牵连）。
