## 3. 改了什么

`build_questionnaire_pdf` 尾部四行折成一行语句＋两行注释：

```
    # fpdf2 2.8.x 的 output() 返 bytearray，与本函数 `-> bytes` 声明不符 ⇒ 出口统一折成 bytes。
    # 原处那段两支同返的恒真判别（s924-06 遗留／s927-43 出形状）由 s927-55 清成下面这一行。
    return bytes(pdf.output())
```

**可执行语句净变：−4/+1**（`out = pdf.output()` 与两条 `return` 合一），注释 +2 ⇒ numstat 3/4。
卷宗说的"1 行级 diff"指语句层，注释行是为留溯源；**净语句数其实是减 3**，此点如实标注。

为什么这是**零行为变化**（不是"看起来一样"）：

1. 两支体逐字相同（都 `return bytes(out)`）⇒ 条件真/假都返回同一表达式，判别不进结果。
2. 本仓 `.venv` 现探 `fpdf2 2.8.7`：`type(FPDF().output())` = **`bytearray`**，
   `isinstance(out, bytes)=False`、`isinstance(out, bytearray)=True`、`bytes(out)==out=True`
   ⇒ 现场走的是 if 支，而 if 支与 else 支同体，删判别不动路径语义。
3. `str` 情形（老版 fpdf 才可能）两支都会 `bytes(str)` 抛 `TypeError` ⇒ 清理前后一致，
   **没有**借清理偷偷改这条降级口径（要改属裁决面，另单）。
4. `-> bytes` 声明（`:497` 起的签名）在清理后**第一次真的被单点保证**，不再靠一段死分支充数。
