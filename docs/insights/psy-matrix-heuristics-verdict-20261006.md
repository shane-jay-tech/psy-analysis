- **漏检实证**：「未来研究需要扩大样本并采用纵向设计。」——现值表（局限/limitation/limited/constrained/drawback/caveat）零命中 ⇒ 返回空串，**漏检实锤**（学术摘要局限常以「未来研究」表述）。
- **扩充候选与误命中评估**：

| 候选词 | 误命中风险 | 评估 |
|---|---|---|
| 未来研究 | 低（固定搭配） | **推荐收**——最常见局限引导语 |
| future research | 低 | 推荐收（英文对称） |
| 未来 | **高**（「未来方向」「未来工作」之外的正文叙述「未来发展」会误中） | 不收单词，收「未来研究/未来需」二元组 |
| 不足 | 中（「样本量不足」常与局限同现，但「系统不足」类正文亦多） | 缓收（观察误报后再定） |
| 然而/however | 高（转折词非局限标记） | 不收 |
