## 1. manova（多变量方差分析）

- 注册：runner.py:335 `@_register("manova")`；合入位置建议：插在 interpretation.py `two_way_anova` 分支（:171）之后、方差分析家族邻域。
- **适用研究设计**：一个分组自变量（≥2 水平）+ 两个及以上连续因变量，考察组间在因变量组合上的联合差异。
- **主要统计量及读取**：Pillai's Trace（最稳健，优先报告，越接近 1 越强）、Wilks' Λ（越接近 0 越强）、近似 F 与 p；显著后做**单因变量 ANOVA/事后比较**追踪哪个因变量驱动差异。
- **效应量口径**：偏 η²（per 因变量）或 multivariate η²；报告时逐因变量给出。
- **常见误读**：只看单变量 ANOVA 不看联合检验；多元显著≠每个因变量都显著；须检查方差-协方差矩阵同质（Box's M）与多元正态。
- **APA 句式示例**：`采用 MANOVA 考察组间在 X1、X2 上的联合差异，Pillai's Trace = V, F(df1, df2) = F, p = P，偏 η² = E。`
- 待统计口径评审：Pillai 与 Wilks 的首选口径按教材统一。

## 2. hlm（多层线性模型）

- 注册：runner.py:350；合入位置建议：`hierarchical_regression` 分支邻域（回归家族区块）。
- **适用**：嵌套数据（学生嵌套于班级、重复测量嵌套于个体）。
- **统计量读取**：ICC（组间变异占比，≥0.059 通常有建模必要）、固定效应系数 β 及其 SE/p、随机效应方差成分（是否显著因组而异）。
- **效应量口径**：R²（按层分解）或方差削减比例；HLM 无单一统一效应量，逐层报告。
- **常见误读**：忽略 ICC 直接跑 OLS；把随机斜率显著性当作固定效应显著性；组中心化与总中心化混用。
- **APA 句式示例**：`ICC = 0.I，建立两层模型；X 对 Y 的固定效应 β = B, SE = S, t = T, p = P；随机斜率方差 = V。`
- 待统计口径评审：估计器（REML/ML）口径与自由度近似（Satterthwaite）按项目规范统一。

## 3. sem（结构方程模型）

- 注册：runner.py:367；合入位置建议：`cfa`/`mediation` 分支邻域（潜变量区块）。
- **适用**：含潜变量与测量误差的路径/验证性因子模型。
- **统计量读取**：拟合三件套 CFI/TLI≥0.90、RMSEA≤0.08（含 90%CI）、SRMR≤0.08；路径系数看标准化 β 与 p；间接效应看 Bootstrap CI。
- **效应量口径**：标准化路径系数 β；R²（内生变量）。
- **常见误读**：只报 χ²（对样本量敏感）；拟合好≠理论正确；不改模型反复拟合至达标（需声明）。
- **APA 句式示例**：`模型拟合良好：χ²(df) = C, p = P, CFI = C, TLI = T, RMSEA = R (90% CI [L, U]), SRMR = S；路径 X→Y 的标准化系数 β = B, p = P。`
- 待统计口径评审：CFI/TLI 阈值口径（0.90 vs 0.95）按教材统一。

## 4. mixed_anova（混合设计方差分析）

- 注册：runner.py:164；合入位置建议：`repeated_anova`/`two_way_anova` 分支邻域。
- **适用**：至少一个被试内因素 + 一个被试间因素的混合设计。
- **统计量读取**：组间主效应、组内主效应、交互作用三项逐一读取；交互显著后做简单效应分析；Mauchly 球形性显著时用 Greenhouse-Geisser 校正 p。
- **效应量口径**：偏 η²（逐效应）。
- **常见误读**：交互不显著却解读"交叉"；未报告校正后的自由度（如 p < .05, GG-corrected）；忽略被试间方差同质（Levene）。
- **APA 句式示例**：`组内主效应显著，F(df_GG, df_e) = F, p = P, η²p = E；交互作用 F = F, p = P。`

## 5. binary_logistic（二项 logistic 回归）

- 注册：runner.py:297；合入位置建议：回归家族区块（`multiple_regression` 分支之后）。
- **适用**：二分类因变量的概率建模。
- **统计量读取**：Exp(B)=OR——OR>1 为风险/促进因素、<1 为保护因素；95%CI 含 1 则不显著；模型层面看 Hosmer-Lemeshow 与伪 R²。
- **效应量口径**：OR（主）；必要时报标准化系数或边际效应。
- **常见误读**：把 OR 当 RR 直接解读为"风险倍数"；混淆"系数显著"与"分类准确率"。
- **APA 句式示例**：`X 对 Y 的预测显著，B = B, Wald χ²(1) = W, p = P, OR = O, 95% CI [L, U]。`

## 6. ordinal_logistic（有序 logistic）

- 注册：runner.py:309；合入位置建议：紧随 binary_logistic 分支。
- **适用**：有序多分类因变量（等级/程度）。
- **统计量读取**：平行线假定（Brant 检验）通过后读共同 OR；模型似然比检验整体显著。
- **效应量口径**：OR（同上）；伪 R²（Nagelkerke）辅助。
- **常见误读**：忽略平行线假定直接读 OR；把阈值的截距当效应解释。
- **APA 句式示例**：`有序 logistic 回归显示 X 与 Y 等级显著相关，OR = O, 95% CI [L, U], p = P；平行线假定检验 χ² = C, p = P。`
- 待统计口径评审：连接函数（logit/probit）口径。

## 7. multinomial_logistic（多分类 logistic）

- 注册：runner.py:321；合入位置建议：紧随 ordinal_logistic 分支。
- **适用**：无序多分类因变量（参照组对比）。
- **统计量读取**：以参照组为基线的逐组 OR；似然比检验逐自变量整体显著；分类准确率表辅助。
- **效应量口径**：OR（相对参照组）。
- **常见误读**：把"相对参照组"读成"相对所有组"；忽略参照组选择对 OR 方向的影响。
- **APA 句式示例**：`以 R 为参照，X 每增加一单位，落入 G 组（相对 R 组）的 OR = O, 95% CI [L, U], p = P。`

## 8. hierarchical_regression（层级回归）

- 注册：runner.py:282；合入位置建议：`multiple_regression` 分支之前（回归家族区块头部）。
- **适用**：按理论 blocks 分步进入预测变量，考察增量解释（如控制人口学后 X 的 ΔR²）。
- **统计量读取**：逐模型的 R²、ΔR² 及其 F 检验；目标变量的 β 与 p（读最终模型）。
- **效应量口径**：ΔR²（逐步）+ 最终模型 R²。
- **常见误读**：比较各步 β 时忽略共线性；把"进入顺序"当作因果顺序。
- **APA 句式示例**：`控制 Z 后，X 解释 Y 的增量方差 ΔR² = D, F(1, df) = F, p = P；β = B。`

## 9. multiple_regression（多元线性回归，linear_regression 同模板简版）

- 注册：runner.py:269（multiple_regression）/ :256（linear_regression）；合入位置建议：回归家族区块。
- **适用**：多个连续/虚拟预测变量对连续因变量的联合预测。
- **统计量读取**：整体 F、逐变量非标准化 B（含单位解释）与标准化 β（相对强度）、tolerance/VIF 共线性诊断。
- **效应量口径**：R²、校正 R²、逐变量偏相关或半偏相关平方。
- **常见误读**：用 β 比较不同量纲变量的"重要性"时混淆 B 与 β；忽略共线性导致符号翻转。
- **APA 句式示例**：`回归整体显著，R² = R, F(k, df) = F, p = P；X 的 β = B, t = T, p = P。`

## 10. welch_anova（Welch 校正单因素方差分析）

- 注册：runner.py:127；合入位置建议：`one_way_anova` 分支之后（方差分析家族）。
- **适用**：组间方差不同质时的单因素均值差异检验（对方差不等稳健）。
- **统计量读取**：Welch F 与近似自由度（非整数是特征而非错误）；显著后 Games-Howell 事后比较。
- **效应量口径**：ω² 或 η²（按组报告，注明方差不等口径）。
- **常见误读**：方差齐性检验显著却仍读普通 ANOVA 的 F；事后比较沿用 Tukey（假定方差齐）而非 Games-Howell。
- **APA 句式示例**：`因方差齐性假设不成立，采用 Welch ANOVA，F(2, df) = F, p = P，ω² = E；Games-Howell 事后显示…`
